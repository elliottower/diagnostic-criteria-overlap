# diagnostic-criteria-overlap

Apparatus for a methods paper on comparisons between diagnostic criteria: where a study
prints a coefficient instead of the table it was computed from, the table can often be
recovered from the figures the study does print.

## The claim

Two diagnostic criteria applied to one population yield a 2x2 table. A study comparing
them usually publishes Cohen's kappa rather than that table, and the same kappa arises
from tables that mean opposite things — one where a criterion's positive class is nested
inside the other's, so switching criteria only adds diagnoses, and one where each
criterion names patients the other does not.

A sample size, both positive marginals and kappa determine the table exactly. Printed
figures are rounded, so they identify a finite set of integer tables instead. Enumerating
every table whose statistics round back to the printed digits returns the source table by
construction, and reports when no table reproduces all the published figures.

Across 16 published comparisons spanning 8 conditions, 9 carried enough printed figures to
attempt recovery: 7 identify a single table, 1 identifies eleven, and 1 admits none.

## What is here

    experiments/               the frozen registration and the input figures
    results/recovery.json      the enumeration for every comparison, with the sentence
                               each input figure was read from
    results/                   26 records, one per computed table, figure or check
    scripts/                   40 scripts; every table and figure in the manuscript is
                               generated by one of them
    claims/                    11 quotation records, one per cited source
    reference/FETCH_LOG.json   artifact ledger: the SHA-256 and retrieval tier of each
                               of 89 sources
    figures/                   the figures, and the TikZ that draws them
    references.bib             84 entries
    docs/provenance.md         what was measured, what changed, and what was found wrong
                               while the paper was prepared

The manuscript is not in this repository. The stored copies of the sources are
third-party copyrighted text and are not redistributed; the ledger records the SHA-256 of
each, so an independently retrieved copy can be checked against it.

## Verifying

The enumeration is exact rational arithmetic and depends on no stored source:

    python3 scripts/recover_tables.py

regenerates `results/recovery.json`. Two external checks are included.
`scripts/compare_conv2x2.py` runs the point reconstruction in `metafor`'s `conv.2x2`
against the enumeration on the comparisons whose sources print their cells;
`scripts/mlscorecheck_crosscheck.py` runs `mlscorecheck` wherever it applies.

With the sources retrieved into `reference/`:

    python3 scripts/audit_tex_quotes.py <manuscript>.tex

reports every quotation in the manuscript and whether it resolves in the source it cites.
A quotation that cannot be located is reported by line number rather than passed over.

Without those sources, `citations verify --claims claims` reports all 27 quotations as
`unchecked`, not as passing. That is the intended behaviour: a run that read no source is
not a run that found no fault.

## One source is not public

One comparison uses aggregate counts supplied by the corresponding author of the source
study, who gave permission to cite the correspondence and to report the tables. The counts
are in `results/daghi_author_confirmation.json`, which records that the reconstruction was
run and stored before the request was sent. The correspondence itself is not here.

## Software

The enumeration is packaged as [`enum2x2`](https://pypi.org/project/enum2x2/), with an R
port. Both are cited in `references.bib` with their version and DOI.
